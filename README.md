A single funny line for the make.fun competition
[One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3).
The program (`main.ts`) writes exactly one line to `entry.txt` — nothing else.

> My Roomba mapped my apartment, filed for custody of the dust bunnies, and won.

The joke: a robot vacuum starts out doing its ordinary job, then the line
turns — it sues for custody of the dust bunnies, and wins.
